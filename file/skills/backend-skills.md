# OneChat 后端技能文档

## 1. 项目架构

### 1.1 整体架构
- **技术栈**: Spring Cloud Alibaba 2023.0.1.2 + Spring Boot 3.3.5 + MyBatis-Plus 3.5.10.1
- **微服务架构**: 基于Spring Cloud的微服务体系
- **通信方式**: Feign接口调用
- **消息队列**: RabbitMQ (Spring Cloud Stream)
- **缓存**: Redis (Redisson)
- **WebSocket**: TIO 3.8.7
- **AI集成**: LangChain4j 1.0.0-beta3

### 1.2 模块结构

#### 1.2.1 OneChat-modules (具体业务服务)
- **OneChat-ai**: AI模块，提供智能回复等AI能力
- **OneChat-auth**: 系统应用凭证生成模块，处理登录认证
- **OneChat-file**: 系统文件服务模块，处理文件上传下载
- **OneChat-Gateway**: 系统网关模块，处理请求路由和过滤
- **OneChat-im**: 系统客户会话聊天模块，基于TIO实现WebSocket通信
- **OneChat-system**: 系统组织架构，菜单管理，登陆日志，角色管理等模块
- **OneChat-ops**: 运营相关功能模块

#### 1.2.2 OneChat-api (对外暴露的接口)
- **OneChat-api-im**: 聊天相关接口
- **OneChat-api-ops**: 运营相关接口
- **OneChat-api-system**: 系统管理相关接口

#### 1.2.3 OneChat-common (基础服务)
- **OneChat-common-core**: 系统公共参数，常量，注解相关配置
- **OneChat-common-datascope**: 系统数据权限处理的相关注解
- **OneChat-common-datasource**: 多数据源支持
- **OneChat-common-log**: 系统日志记录
- **OneChat-common-mq**: 系统消息队列模块
- **OneChat-common-redis**: 系统Redis缓存模块
- **OneChat-common-security**: 系统安全模块
- **OneChat-common-sensitive**: 数据脱敏模块

## 2. 核心功能

### 2.1 聊天系统 (OneChat-im)
- **基于TIO的WebSocket实现**: 提供实时聊天功能
- **客户分配策略**: 支持随机分配、轮询分配、最少忙碌分配等多种策略
- **消息处理**: 消息发送、接收、存储和转发
- **会话管理**: 访客会话状态管理

### 2.2 AI模块 (OneChat-ai)
- **智能回复**: 基于LangChain4j实现的AI回复功能
- **模型管理**: 支持多种AI模型配置
- **Prompt管理**: 提供Prompt模板配置和管理

### 2.3 认证授权 (OneChat-auth)
- **JWT认证**: 基于JWT的令牌生成和验证
- **访客登录**: 支持访客临时登录
- **密码管理**: 密码加密和验证

### 2.4 文件服务 (OneChat-file)
- **文件上传**: 支持本地存储
- **文件管理**: 提供文件的上传、下载、删除等功能
- **安全过滤**: 实现Referer过滤等安全措施

### 2.5 系统管理 (OneChat-system)
- **组织架构**: 部门管理
- **用户管理**: 用户信息管理
- **角色管理**: 角色权限管理
- **菜单管理**: 系统菜单配置
- **日志管理**: 登录日志和操作日志

### 2.6 网关服务 (OneChat-gateway)
- **请求路由**: 基于Spring Cloud Gateway的请求路由
- **安全过滤**: 实现认证、验证码、XSS过滤等
- **限流熔断**: 集成Sentinel实现限流和熔断

## 3. 技术实现

### 3.1 安全认证
- **JWT令牌**: 使用jjwt库实现JWT令牌的生成和验证
- **权限注解**: 自定义注解实现方法级权限控制

### 3.2 数据处理

### 3.3 缓存管理

- **缓存键管理**: 统一的缓存键生成策略
- **缓存过期**: 合理的缓存过期时间设置

### 3.4 消息队列
- **Spring Cloud Stream**: 简化消息队列操作
- **RabbitMQ**: 作为消息中间件

### 3.5 WebSocket通信
- **TIO框架**: 高性能WebSocket实现
- **会话管理**: 维护用户和访客的WebSocket连接
- **消息推送**: 实时消息推送功能

### 3.6 AI集成
- **LangChain4j**: 提供AI模型集成能力
- **OpenAI API**: 集成OpenAI的API
- **Prompt工程**: 优化AI提示词

## 6. 核心API

### 6.1 认证相关
- **登录接口**: `/auth/login` - 用户登录
- **访客登录**: `/auth/guest/login` - 访客临时登录
- **令牌刷新**: `/auth/refresh` - 刷新令牌

### 6.2 聊天相关
- **WebSocket连接**: `/im/ws` - WebSocket连接地址
- **发送消息**: 基于WebSocket协议
- **历史消息**: `/im/messages` - 获取历史消息

### 6.3 文件相关
- **文件上传**: `/file/upload` - 上传文件
- **文件下载**: `/file/download/{fileId}` - 下载文件
- **文件删除**: `/file/delete/{fileId}` - 删除文件

### 6.4 系统管理
- **用户管理**: `/system/user` - 用户CRUD操作
- **角色管理**: `/system/role` - 角色CRUD操作
- **菜单管理**: `/system/menu` - 菜单CRUD操作
- **部门管理**: `/system/dept` - 部门CRUD操作
